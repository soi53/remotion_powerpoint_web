# KR-ACADEMY MOVIE MAKER 사용 설명서

이 프로그램은 여러분이 만든 파워포인트(PPT) 파일을 바탕으로 AI 성우가 읽어주는 고품질 강의 영상을 만들어 줍니다. 복잡한 영상 편집 지식 없이도, 아래 안내에 따라 차근차근 따라오시면 됩니다.

---

## 처음 설치하기 (최초 1회만)

### 필요한 프로그램

이 프로그램을 사용하려면 아래 두 가지가 컴퓨터에 설치되어 있어야 합니다.

1. **Microsoft PowerPoint**: 슬라이드를 이미지로 변환할 때 사용합니다. 일반적으로 Office 설치 시 포함됩니다.
2. **Node.js**: 웹 서버를 실행하기 위한 프로그램입니다. https://nodejs.org 에서 무료로 다운로드할 수 있습니다. "LTS" 버전을 받으세요.

### API 키 준비

이 프로그램은 AI 서비스를 이용하기 때문에 API 키(일종의 사용 허가증)가 필요합니다.

**ElevenLabs API 키** (AI 성우 목소리 생성에 필요)
1. https://elevenlabs.io 에 접속하여 회원가입 또는 로그인합니다.
2. 오른쪽 위 프로필 아이콘 클릭 → **Profile** 클릭
3. **API Keys** 탭에서 키를 복사합니다.

**OpenAI API 키** (번역 기능 사용 시 필요)
1. https://platform.openai.com/api-keys 에 접속합니다.
2. **Create new secret key** 버튼을 눌러 키를 생성하고 복사합니다.

## 프로그램 시작하기

### 방법 1: start.bat 파일 실행 (권장)

1. 프로그램 폴더(`remotion_powerpoint_web`)를 엽니다.
2. `start.bat` 파일을 **더블클릭**합니다.
3. 처음 실행 시 검은 창이 열리면서 API 키 입력 안내가 나옵니다.
   - 메모장이 자동으로 열리면, `ELEVENLABS_API_KEY=` 뒤에 복사한 키를 붙여넣기 합니다.
   - `OPENAI_API_KEY=` 뒤에도 마찬가지로 입력합니다.
   - 저장(Ctrl+S) 후 메모장을 닫습니다.
4. `start.bat`을 다시 더블클릭합니다.
5. 잠시 후 인터넷 브라우저가 자동으로 열리면서 프로그램이 시작됩니다.

> 두 번째 실행부터는 더블클릭 한 번으로 바로 시작됩니다.

### 방법 2: 브라우저 직접 접속

서버가 이미 실행 중이라면 브라우저 주소창에 아래를 입력하고 Enter를 누르세요.
```
http://localhost:3000
```

## 화면 구성 안내

프로그램이 열리면 화면 왼쪽에 단계 메뉴가 있습니다.

```
1단계: 파일 업로드   ← PPT 파일 올리기
2단계: 나레이션 편집  ← 각 슬라이드의 대본 작성
3단계: TTS 생성      ← AI 성우로 음성 파일 만들기
4단계: 프리뷰        ← 완성 영상 미리 확인
5단계: 렌더 & 다운로드 ← 최종 MP4 파일로 저장
```

순서대로 진행하면 됩니다. 각 단계는 언제든지 다시 돌아와 수정할 수 있습니다.

## 1단계: 파일 업로드

### PPTX 파일 올리기

1. 화면에서 **"PPTX 파일"** 영역을 클릭하거나, PPT 파일을 그 위로 끌어다 놓습니다.
2. 파일 선택 창이 열리면 준비한 `.pptx` 파일을 선택합니다.
3. 선택하면 자동으로 업로드가 시작됩니다. 진행 상황이 화면에 표시됩니다.
4. "완료! 슬라이드 N장 추출됨" 메시지가 나오면 성공입니다.

> 주의: .pptx 형식만 가능합니다. 구버전 .ppt 형식은 지원하지 않습니다.

### 스크립트 파일 올리기 (선택 사항)

이미 PPT 슬라이드 노트에 대본이 있거나, 별도의 텍스트 파일로 대본을 준비했다면 자동으로 불러올 수 있습니다.

스크립트 파일 형식 (`.txt` 파일):
```
[1]
첫 번째 슬라이드의 나레이션 내용을 여기에 씁니다.

[2]
두 번째 슬라이드의 나레이션 내용을 여기에 씁니다.
```

- `[1]`, `[2]` 처럼 대괄호 안에 슬라이드 번호를 적습니다.
- PPTX 업로드 완료 후 "스크립트 파일" 영역에 드래그하거나 클릭하여 올립니다.

> 참고: PPTX 파일 안에 슬라이드 노트가 있으면 나레이션이 자동으로 채워집니다. 스크립트 파일을 별도로 올릴 필요가 없습니다.

### 기존 프로젝트 덮어쓰기

이전에 작업하던 파일이 있는 상태에서 새 PPTX를 올리면, 덮어쓰기 확인 창이 나옵니다. 기존 작업을 지우고 새로 시작하려면 **"덮어쓰기"** 버튼을 누르세요.

### 프로젝트 초기화 버튼

화면 오른쪽 위의 **"프로젝트 초기화"** 버튼을 누르면 현재 작업 중인 슬라이드, 오디오, 설정 파일이 모두 삭제됩니다. 처음부터 새로 시작하고 싶을 때 사용하세요.

> 주의: 초기화하면 복구가 불가능합니다. 확인 창에서 "초기화" 버튼을 눌러야 실제로 삭제됩니다.

## 2단계: 나레이션 편집

이 단계에서 각 슬라이드에 AI 성우가 읽을 대본을 작성합니다.

### 화면 구성

- **왼쪽 패널**: 전체 슬라이드 목록. 클릭하면 해당 슬라이드가 오른쪽에 열립니다.
- **가운데**: 선택된 슬라이드 이미지와 편집 도구.
- **위쪽 진행바**: 몇 개 슬라이드에 나레이션이 작성됐는지 표시됩니다.

### 나레이션 텍스트 입력

1. 왼쪽에서 편집할 슬라이드를 클릭합니다.
2. 슬라이드 이미지 아래 텍스트 입력란에 대본을 입력합니다.
3. **저장 버튼**을 누르거나 `Ctrl+S`를 누르면 저장됩니다.

> 팁: 슬라이드 노트에 내용이 있으면 자동으로 채워져 있습니다.

### 슬라이드 길이 조정

- "슬라이드 길이 (초)" 칸에서 이 슬라이드가 영상에서 몇 초 동안 보일지 설정합니다.
- TTS를 생성하면 실제 음성 길이에 맞게 자동으로 업데이트됩니다.

### 자막 켜기/끄기

화면 오른쪽 위의 **"자막"** 스위치를 클릭하면 자막이 켜지거나 꺼집니다.
- 파란/보라색으로 켜져 있으면 최종 영상에 자막이 표시됩니다.
- 회색으로 꺼져 있으면 자막 없이 영상이 만들어집니다.

> 이 설정은 즉시 저장되어 렌더링 때 자동으로 적용됩니다.

### 전체 번역 기능

영어, 일본어 등 다른 언어로 나레이션을 번역하고 싶다면:
1. 오른쪽 위의 언어 선택 드롭다운에서 원하는 언어를 고릅니다.
2. **"전체 번역"** 버튼을 누릅니다.
3. 잠시 후 모든 슬라이드의 나레이션이 해당 언어로 바뀝니다.

> 주의: 번역하면 기존 나레이션이 덮어씌워집니다. 원본이 필요하다면 미리 별도 파일에 저장해 두세요.

### 줌인 효과 설정 (zoom_to)

특정 슬라이드에서 화면을 일부 영역으로 확대하고 싶을 때 사용합니다.

1. 슬라이드 에디터 하단의 **"zoom_to 설정"** 영역에서 **"영역 지정"** 버튼을 클릭합니다.
   - 버튼이 노란색으로 바뀌고, 마우스 커서가 십자(+) 모양으로 변합니다.
2. 슬라이드 이미지 위에서 마우스를 **클릭한 채로 드래그**하여 확대할 영역을 선택합니다.
   - 노란 테두리 사각형이 그려집니다.
3. 원하는 영역이 선택됐으면 **"저장"** 버튼을 누릅니다.
4. 잘못 선택했다면 **"제거"** 버튼을 눌러 취소합니다.

> 영상에서 어떻게 보이는지는 4단계 프리뷰에서 확인하세요.

## 3단계: TTS 생성

나레이션 대본을 실제 AI 성우 음성 파일로 변환합니다.

### 성우(목소리) 선택

1. **"성우 선택"** 드롭다운을 클릭합니다.
2. 목록에서 원하는 성우를 고릅니다.
   - 각 성우 이름 옆 **▶ 미리듣기** 버튼을 눌러 목소리를 들어볼 수 있습니다.
   - 기본 성우: Matilda (여성, 다국어 지원, 무료)
   - 한국어에 최적화된 성우는 유료 플랜에서 추가로 사용 가능합니다.

### 생성 옵션

- **"--force (기존 파일 덮어쓰기)"** 체크박스: 이미 생성된 음성 파일도 모두 다시 만듭니다. 목소리를 바꾸거나 나레이션을 크게 수정했을 때 사용하세요.
- **"--retry-failed (실패 항목만 재시도)"** 체크박스: 이전에 오류가 발생한 슬라이드만 다시 시도합니다.

### TTS 생성 시작

**"TTS 생성 시작"** 버튼을 누릅니다.

- 진행 상황 패널이 나타나면서 슬라이드별로 생성 상태가 표시됩니다.
- 슬라이드 수에 따라 수 분이 걸릴 수 있습니다.
  - 무료 플랜: 슬라이드당 약 5~10초
  - 유료 플랜: 슬라이드당 약 1~2초

### 생성 결과 확인

- 초록색 체크(✓): 생성 완료
- 빨간 X(✗): 오류 발생 (나레이션이 비어 있거나 API 오류)
- 회색(-): 나레이션 없는 슬라이드 (건너뜀)

모든 슬라이드가 완료되면 다음 단계로 이동합니다.

## 4단계: 프리뷰 (미리보기)

최종 렌더링 전에 영상이 어떻게 만들어지는지 확인합니다.

1. **재생 버튼(▶)** 을 눌러 미리보기를 시작합니다.
2. 성우 음성, 슬라이드 전환, 줌인 효과, 자막 등을 확인합니다.
3. 수정이 필요하면 상단 메뉴로 이전 단계로 돌아갑니다.

> 이 미리보기는 Remotion Studio 엔진을 통해 실제 렌더링과 동일한 결과를 보여줍니다.

---

## 5단계: 렌더 & 다운로드

모든 준비가 완료됐으면 MP4 영상 파일을 만드는 마지막 단계입니다.

1. **"렌더 시작"** 버튼을 누릅니다.
2. 진행 상황이 퍼센트로 표시됩니다. 슬라이드 수에 따라 수 분이 소요됩니다.
3. 완료되면 "렌더 완료!" 메시지가 나타나고, 파일이 저장됩니다.

### 저장 위치

완성된 MP4 파일은 컴퓨터의 **"다운로드" 폴더**에 `presentation.mp4` 이름으로 저장됩니다.

- Windows: `C:\Users\사용자이름\Downloads\presentation.mp4`

**"다시 다운로드"** 버튼을 누르면 브라우저로 다시 내려받을 수 있습니다.

## 자주 묻는 질문 (FAQ)

### Q. 자막이 영상에 나오지 않아요
2단계 나레이션 편집 화면 오른쪽 위의 **"자막"** 스위치가 켜져 있는지 확인하세요. 스위치가 파란색이면 켜진 상태입니다.

### Q. 목소리가 이상하게 들려요
3단계에서 다른 성우를 선택한 뒤, **"--force"** 체크박스에 체크하고 TTS를 다시 생성하세요.

### Q. 줌인 효과가 영상에서 안 나와요
2단계에서 줌 영역을 지정한 후 반드시 **"저장"** 버튼을 눌러야 합니다. 저장 버튼을 누르지 않으면 영상에 반영되지 않습니다.

### Q. TTS 생성이 너무 느려요
ElevenLabs 유료 플랜을 사용하면 훨씬 빠릅니다. `.env` 파일에 `ELEVENLABS_PLAN=paid` 줄 앞의 `#`을 지워서 활성화하세요.

### Q. "API 오류"가 났어요
- `.env` 파일의 API 키가 올바른지 확인하세요.
- ElevenLabs 무료 플랜은 월 10,000자 생성 제한이 있습니다. 크레딧을 확인하세요.

### Q. 새 프로젝트로 시작하고 싶어요
1단계 업로드 화면 오른쪽 위의 **"프로젝트 초기화"** 버튼을 누르세요. 모든 기존 데이터가 삭제되고 새로 시작할 수 있습니다.

### Q. 렌더링 중에 오류가 났어요
- 3단계에서 TTS 생성이 모두 완료됐는지 확인하세요.
- 오디오 파일이 없는 슬라이드가 있으면 렌더링이 실패할 수 있습니다.
- 브라우저를 새로고침한 후 다시 시도하세요.

### Q. 포트 3000이 이미 사용 중이라고 나와요
이미 다른 프로그램이 3000번 포트를 쓰고 있습니다. `web/package.json` 파일의 `"dev": "next dev --port 3001"` 처럼 포트를 바꾼 후 재시작하세요. 브라우저 접속 주소도 `http://localhost:3001`로 변경됩니다.

## 영상 제작 전체 흐름 요약

```
PPT 파일 준비
    ↓
[1단계] PPTX 업로드 → 슬라이드 이미지 자동 추출
    ↓
[2단계] 각 슬라이드에 나레이션(대본) 입력
        + 필요한 슬라이드에 줌인 효과 설정
        + 자막 켜기/끄기 설정
    ↓
[3단계] AI 성우 선택 → TTS 음성 파일 자동 생성
    ↓
[4단계] 미리보기로 결과 확인
    ↓
[5단계] 렌더링 → 다운로드 폴더에 MP4 저장
```
